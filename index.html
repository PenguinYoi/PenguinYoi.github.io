What are U.S. states legislating about?

2025 state legislation · 50 states + D.C.

What works today

State and topic filters, bill search, source links, review-status filters, and monthly timeline playback.

Technical approach

A Python classification pipeline and a static JavaScript map using versioned JSON. Experiments compare keyword, embedding, and hybrid topic classification.

Reading the results

The MVP distinguishes source-checked enactments from legislature-passed bills with unverified signatures. Proposed topic labels and incomplete coverage limit interpretation.

Development notes & limitations

PolyViz is an exploratory project, not a complete legislative inventory or a validated measure of state priorities. Classifier evaluation and cross-state transfer remain active areas of investigation. See the repository for datasets, evaluation results, source provenance, and current limitations.
