What are states
legislating about?

Legislative databases hold a lot of information. Getting a readable picture across states is a different problem.

I’m building PolyViz, an interactive map of 2025 state legislation organized by topic, geography, and time. It brings state and topic filters, bill search, source links, and monthly playback into one place.

Explore the live mapCode & methodology

The approach

A Python classification pipeline and a static JavaScript map using versioned JSON. Experiments compare keyword, embedding, and hybrid topic classification.

The open question

How can automated topic labels be useful without hiding uncertainty? The map distinguishes source-checked enactments from legislature-passed bills with unverified signatures.

A note on interpreting the map

PolyViz is an exploratory MVP, not a complete legislative inventory or a validated measure of state priorities. Topic proposals and incomplete coverage limit interpretation. Evaluation and cross-state transfer remain areas of investigation; the repository documents the current methods and limitations.
